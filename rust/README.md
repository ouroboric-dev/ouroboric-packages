# ouroboric

The official crate of the [Ouroboric](https://ouroboric.dev) project, which builds open,
self-improving software factories. For now it only identifies the project:

```
$ cargo install ouroboric
$ ouroboric
Ouroboric: open, self-improving software factories.
Website: https://ouroboric.dev
Source:  https://github.com/ouroboric-dev
```
